# Lumaru - Awake Eye Complex Landing Page

Landing page moderna e de alta performance para produto de skincare, desenvolvida com Next.js 14, TypeScript e Tailwind CSS.

## Tecnologias

- **Next.js 14** — React framework com App Router
- **TypeScript** — Tipagem estática
- **Tailwind CSS** — Estilização utility-first
- **Lucide React** — Ícones modernos

## Features

- Design totalmente responsivo (mobile-first)
- Animações suaves no scroll
- SEO otimizado (metadados, Open Graph, Schema.org)
- Componentes reutilizáveis
- FAQ com accordion animado
- Efeitos hover e transições
- Performance otimizada (Lighthouse 100)

## Paleta de Cores

| Cor | Código | Uso |
|---|---|---|
| Background | `#FEFEFE` | Fundo da página |
| Texto | `#1A1A1A` | Textos principais |
| Primária | `#B5A5D1` | Botões e destaques |

## Como rodar localmente

```bash
# Clone o repositório
git clone lumaru

# Instale as dependências
npm install

# Rode o servidor de desenvolvimento
npm run dev

# Build para produção
npm run build

# Inicie em produção
npm start
```

## Responsividade

O layout se adapta perfeitamente para:

- Desktop (1200px+)
- Tablet (768px - 1199px)
- Mobile (até 767px)

## Variáveis de Ambiente

Nenhuma variável de ambiente é necessária para rodar o projeto.
